- Build a federated network of knowledge commons

## Processing Guidelines

### What to Ingest

- Meeting transcripts from community organizing work
- Protocol documentation from practitioners
- External artifacts (papers, books, tools)

### Quality Standards

- All patterns should have clear problem/solution framing
- Protocols must have defined steps and roles
- Sources must be attributed

### Review Criteria

- Is this relevant to civic innovation?
- Is it well-documented and actionable?
- Are sources properly cited?
