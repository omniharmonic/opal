# Loomio

## Summary

A decision-making and coordination tool for groups, enabling asynchronous deliberation and various decision-making processes.

## Features

- Discussion threads
- Multiple decision types (proposals, polls, dot voting)
- Consent-based decision support
- Integration with other tools

## Use Cases

- Team governance
- Cooperative decision-making
- Sociocratic organizations
- Remote group coordination
