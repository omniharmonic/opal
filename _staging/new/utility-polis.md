# Pol.is

## Summary

A machine learning-based tool that uses AI to find consensus points in large-scale discussions by clustering opinions and surfacing areas of agreement.

## Features

- Handles large numbers of participants
- Uses ML to cluster similar opinions
- Identifies consensus points across different groups
- Real-time visualization of opinion landscape

## Use Cases

- Public consultations
- Policy deliberation
- Large community discussions
- Finding common ground across divided groups
