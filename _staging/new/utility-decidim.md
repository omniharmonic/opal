# Decidim

## Summary

A deliberation platform that originated in Barcelona and is now used by cities worldwide for participatory governance processes.

## Features

- Open source platform
- Supports various participation processes
- Proposal creation and discussion
- Voting and prioritization
- Modular and customizable

## Use Cases

- Municipal participatory processes
- Participatory budgeting
- Public consultations
- Strategic planning
